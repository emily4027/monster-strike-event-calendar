## 先看這裡：資料怎麼流動

```
官網公告 ──(爬蟲，每天中午)──┬─→ 活動清單（Firestore shared/events，直接寫入）
                              └─→ 卡池 pools.json、角色名冊 characters.json（開 PR，你確認後 Merge）

你在網頁上的修改
  ├─ 行事曆編輯活動 ──→ Firestore shared/events（立刻生效）
  ├─ 角色頁名稱修正 ──→ Firestore shared/characters（抽卡紀錄裡打錯的名稱）
  └─ 角色頁編輯模式（含手動補卡池）──→ Firestore shared/roster（立刻生效）──(爬蟲，每天中午)──→ 寫回 characters.json、pools.json

網頁（行事曆、角色頁） ←── 讀上面全部 ＋ 你的抽卡紀錄（只讀，絕對不寫）
抽卡統計的角色按鈕     ←── 只讀 pools.js、pools.json
```

三個重點：

1. **卡池和名冊的「正本」是 repo 裡的兩個 JSON 檔。** 爬蟲改它們一定開 PR 給你看；只有「寫回你自己在編輯模式的修改」是直接 commit。
2. **你在網頁上的修改立刻生效**，因為網頁讀檔後會套上 Firestore 裡的修改。抽卡統計只讀檔案，所以要等爬蟲寫回才跟上（最慢隔天）。
3. **抽卡紀錄只讀不寫。** 這個網站任何功能都不會改到你的抽卡紀錄。

## 2026-11-15　儲存時撞名，可以直接合併

**起因**：改名時打了別隻角色的名稱，只會跳錯誤，還要自己到下面「這隻其實是另一隻角色」重打一次名稱才能合併。

**現在的樣子**

1. 按「儲存」（或「加進名冊」）時，如果名稱、別名或形態名稱已經是別隻角色的名稱，不會存，而是在表單下面說是哪一隻，例如「已經是 c0268「背德手槍」的名稱」。
2. 下面有一個選單（當形態／當別名，預設當形態）和兩個按鈕：
   - 「這隻併進 c0268」：這隻變成 c0268 的形態或別名。
   - 「c0268 併進這隻」：反過來，c0268 變成這隻的形態或別名（新角色沒有這個按鈕）。
3. 按了會先跳確認視窗，確認後就合併。表單裡其他還沒儲存的修改不會存，要的話合併後再改一次。
4. 不是同一隻的話，換一個名稱再存就好。

**沒驗證的**：本機預覽確認撞名時會出現說明和按鈕；合併按鈕本身沒有在線上按過（合併用的是原本「合併過去」那一套，有測試）。

## 2026-11-14　手動補卡池、補上 α 角色的卡池

**起因**：57 隻 α 角色標著「期間限定，還沒有卡池資料」。爬蟲只讀 2023-09 以後的公告，更早的卡池要手動補。

**怎麼用**

1. 編輯模式點開角色，「其他形態」下面有「出自卡池」。
2. 上面列出這隻角色目前在哪些卡池、哪個月。
3. 下面填卡池名稱（會提示既有的卡池名稱）、選年月、公告網址（選填），按「加到卡池」。按了就存，不用再按「儲存」。
4. 列出的卡池旁邊有「拿掉」可以移除。官網的限定角色名單（沒有月份的那種）和合作卡池不能在這裡拿掉。

**規則**

- 同一個卡池名稱、同一個月已經有名單時，角色加進那份名單；沒有就新增一期，類別是限定。
- 卡池名稱比對時忽略空白和全形半形，「祝宴！怪物彈珠新娘4」會加進既有的「祝宴！怪物彈珠新娘 4」。
- 一份名單的角色全部拿掉後，那一期整個移除。
- 加在還沒有編號的新角色身上不行，要等爬蟲編號後再加。
- 和其他修改一樣：這個網站立刻生效，爬蟲每天寫回 `pools.json`，抽卡統計最慢隔天跟上。

**這次補的資料**（我照台版官網公告補的，每一期都附公告網址）

- 21 期期間限定卡池，從 2016-10「怪物彈珠Halloween」到 2026-06「祝宴！怪物彈珠新娘 6」。
- 卡池名稱、年月、角色名稱都照台版公告的寫法，年月是台版轉蛋開始的月份。
- 2015 年的暑假角色（浴衣精靈 忒琪菈α、泳裝少女 諾諾α、撒旦α）找不到台版第一次登場的公告，所以用 2020-08「怪物彈珠暑假 復刻2015」。
- 不只舊卡池，2024-08 暑假、2025-04 學院 5、2025-06 新娘 5、2026-04 學院 6、2026-06 新娘 6 也是爬蟲漏掉的，一起補上。
- 學院 6、新娘 6 的 6 隻角色名冊原本沒有，新增 c0913～c0918，類別期間限定，附上獸神化後的名稱。屬性公告沒寫，先空著。
- 只補每隻角色第一次登場的那期。之後的復刻（每年暑假復刻、跨年 α 轉蛋等）沒有補。

**還沒處理的**

- ~~喀隆α~~：你確認「青蛙公主 喀隆α」就是「喀隆α」。已加成別名，補上獸神化後的名稱「If世界的可愛青蛙公主 喀隆α」，並加進 2020-04「怪物彈珠if 如果的故事」。57 隻現在都有卡池了。
- 爬蟲為什麼漏掉 2024 年以後那幾期新系列，原因還沒查。

**沒驗證的**：「加到卡池」「拿掉」沒有在線上實際按過（本機預覽只看了畫面）；邏輯有測試。

## 2026-11-14　角色本身的圖鑑編號

**起因**：編輯模式只能填「形態」的圖鑑編號，轉蛋抽到的那個形態（角色本身）沒地方填。

**現在**

- 名稱旁邊多了「圖鑑編號」欄，填的是**轉蛋抽到的這個形態**的編號，存在名冊的 `no`。
- 下面的區塊改名叫「其他形態」，填進化後的名稱和各自的編號。
- 「還沒填圖鑑編號」的篩選：角色本身或任何一個形態有編號，就不算沒填。
- 角色編號 `c0001` 這種是內部編號，不能改。它只負責讓卡池指到這隻角色，和遊戲的圖鑑編號無關。
- 「加進名冊」時，如果名稱、別名或形態的名稱已經屬於別的角色，錯誤訊息會寫出是哪一隻的，並提示改用「合併過去」。例如抽卡紀錄寫「孟格菲姐妹α」，形態填「祝宴的熱氣球搭檔 孟格菲姊妹α」，會提示這個形態已經是「孟格菲姊妹α」的。

## 2026-11-14　祭典公告裡另外介紹的期間限定角色

**起因**：你發現世足激獸神（2026-07）的「飛舞於球場之音樂的大天使 聖德芬」沒有在卡池裡。

**原因**：那篇公告把它和「瞄準球門之契約的大天使 梅塔特隆」寫在「介紹在轉蛋中登場的期間限定角色」段落，不在限定角色表裡，爬蟲以前不讀這種段落。我掃過 2023-09 以來的公告，只有這一篇有這種情況。

**現在的規則**

- 祭典公告（有限定角色表的）如果有標題含「轉蛋中登場的期間限定角色」的段落，段落裡寫成「光屬性 ★6 名稱（獸神化・改）」的角色，會加進那期卡池。

- 屬性照段落寫的。
- 段落後面的「可與聖德芬α、聖德芬互相強化合成」只是說明，不會把它們當成同一隻。

**資料的變動**

- 2026-07 世足激獸神：13 隻（原本 11 隻加上這兩隻：c0911、c0912）。
- 2026-08 激獸神祭：原本和 7 月共用名單，現在拆開，維持 11 隻。

**標示的變動**：名冊把角色的類別標成「期間限定」時，就算它在祭典卡池裡，角色頁也標「期間限定：激獸神祭」，不再只標「限定」。其他類別仍然只在角色不屬於任何卡池時才用。

**沒驗證的**：線上頁面沒有開來看，只跑了測試和資料比對。

## 2026-11-13　角色頁的編輯模式、限定與期間限定分開標示

**做什麼用**：讓你直接在網頁上整理角色名冊，不用改 JSON 檔。

**怎麼用**

1. 管理員帳號登入角色頁，點「編輯模式」。
2. 清單換成整份名冊，**有狀況的排前面**，名稱旁邊寫是什麼狀況。
3. 點開角色可以改名稱、屬性、類別、別名、各形態（名稱、形態種類、圖鑑編號）。
4. 「這隻其實是另一隻角色」：把它併成對方的別名或進化形態。合併不能直接復原。
5. 只差一個字的兩隻，按「和○○是不同角色」後不再提示。

**狀況的種類**（排序由前到後）

| 狀況 | 什麼時候出現 | 怎麼處理 |
| --- | --- | --- |
| 爬蟲新增、還沒確認 | 卡池 PR 裡新編號的角色 | 是新角色就按「確認是新角色並儲存」；其實是既有角色就合併 |
| 抽卡紀錄有、名冊沒有 | 你的紀錄裡有、名冊沒有的名稱 | 「加進名冊」，或合併成既有角色的別名 |
| 限定但沒有卡池資料 | 類別是限定／期間限定，但不在任何卡池裡 | 等你給那期的卡池 |
| 沒有屬性 | 名稱不會上色 | 選屬性後儲存 |
| 和別的角色只差一個字 | 例如坂本龍司／坂本龍馬 | 確認是不同角色，或合併 |

另外可以篩選「還沒填圖鑑編號」（目前全部都沒填，所以不算狀況）。

**修改存到哪裡、何時生效**

- 存在 Firestore `shared/roster`（修改檔），轉蛋資料庫的網頁**立刻**套用。
- 爬蟲每天執行時，把修改檔寫回 `characters.json` 和 `pools.json`，直接 commit，提交名稱是「名冊：寫回管理員的修改」。寫回的部分下一次執行時才從修改檔清掉，中途失敗重跑也不會出錯。
- 抽卡統計的角色按鈕讀的是 `pools.json`，所以改名最慢隔天跟上。
- 「加進名冊」的新角色要等寫回時才有編號。如果當時有還沒處理的卡池 PR，會等 PR 處理完才編，避免兩邊編到同一個號碼。
- 沒有刪除功能，因為卡池可能還指著那個編號。多出來的角色用合併處理。

**限定與期間限定**：期間限定也是限定，只是不像祭典每個月都能抽，而是特定活動或節日才有。

- 「限定：卡池」：在限定卡池的名單裡。
- 「期間限定：卡池」：卡池名稱含聖誕、暑假、新娘、學院，或名冊把角色標成期間限定。
- 「期間限定（卡池未知）」：不在任何卡池裡，照名冊的類別。57 隻不在卡池裡的 α 角色先標成這個（非合作的 α 角色一般是期間限定）。
- 其他只在某幾期出現的卡池（真英雄祭、銀河冒險 II、Ultra Charismatic LIVE!! 等），我分不出是哪一種，先標「限定」。哪個該算期間限定，告訴我卡池名稱就能加。

**已驗證**：你存了潘朵拉、梅摩莉α、聖德芬三筆，雲端修改檔正確，套到名冊上沒有衝突。

**沒驗證的**：「寫回檔案」那一步還沒真正執行過，要等下一次排程。

## 2026-11-13　角色名冊（角色 ID 化）

**為什麼要做**：以前所有資料都用角色名稱對應。角色一改名、官網寫法不一致，或出了新的進化形態，卡池、屬性、紀錄就對不起來。

**現在的做法**

- 新增 `characters.json`，每隻角色一筆、一個**內部編號**（`c0001` 起），編了就不改、不重複使用。
- 一筆角色記：名稱（台版官網寫法、轉蛋抽到的形態）、屬性、類別、別名、各形態（名稱、形態種類、遊戲的圖鑑編號）。
- 名稱、別名、任何一個形態的名稱，都找得到這隻角色。比對時忽略空白、間隔號、全形半形。
- 出了新的進化形態，只要在那隻角色底下多加一個形態，卡池和編號都不用動。

**為什麼不直接用圖鑑編號當 ID**：新角色在公告出來時遊戲還沒上線，圖鑑編號還不知道，但爬蟲當下就要寫進卡池。所以 ID 用內部編號，圖鑑編號記在形態上，知道了再填，填錯也不影響任何對應。

**其他檔案的變動**

- `pools.json` 的角色改寫編號。檔案最後附「編號 → 名稱」對照（`names`），給抽卡統計讀。網頁和抽卡統計拿到的仍然是名稱。
- `elements.json`（屬性表）併進名冊，檔案刪除。
- `name-overrides.json` 的名稱對應搬進名冊，變成角色的別名。只在某個卡池才成立的（SPY×FAMILY 夏季造型的三隻 α）保留這個限制。
- 爬蟲讀到名冊沒有的名稱時，在卡池 PR 裡編新編號，PR 說明的「角色名冊」會列出來。

**名冊收哪些角色**：所有讀得到名稱的角色，包含常駐角色（例如真田幸村、洛基），因為公告的屬性名單會列到它們。**名冊不代表限定**，限定與否看卡池。

**上線方式**：抽卡統計會直接讀這邊的檔案，所以分兩次上線：先上「新舊格式都讀得懂」的 `pools.js`，等瀏覽器快取過期後才換資料格式。換完後在線上的抽卡統計確認過，讀到的是名稱、沒有編號。

## 2026-11-13　行事曆：只看參與過的活動

**規則**

- 有抽卡紀錄時，預設只顯示參與過的活動：
  - 免費活動都算參與。
  - 本家、合作、寶珠、沒有標籤的活動，要有抽數才算。
- 進行中和還沒開始的活動一律顯示，不然看不到現在有什麼轉蛋。
- 跟著帳號選單：選單一帳號時，只看那個帳號有沒有抽。
- 勾選「顯示全部活動」看到全部，勾選狀態記在這台瀏覽器。
- 沒有抽卡紀錄時一律顯示全部，勾選框停用。

篩選同時作用在月曆、手機版的當月清單、月份選擇器的小圓點。

**沒驗證的**：手機版清單在整個月都被藏起來時的提示文字，和登入後用雲端紀錄的情況，都沒實際看過。
